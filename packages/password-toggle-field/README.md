# @fictjs/password-toggle-field

Password toggle field primitives for Fict UI primitives, modeled after
`@radix-ui/react-password-toggle-field`.

Exports `PasswordToggleField`, `PasswordToggleFieldInput`,
`PasswordToggleFieldToggle`, `PasswordToggleFieldSlot`,
`PasswordToggleFieldIcon`, and the matching `Root` / `Input` / `Toggle` /
`Slot` / `Icon` aliases.
