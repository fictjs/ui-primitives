# @fictjs/accordion

Accordion primitives for Fict UI primitives, modeled after
`@radix-ui/react-accordion`.

Exports `createAccordionScope`, `Accordion`, `AccordionItem`,
`AccordionHeader`, `AccordionTrigger`, `AccordionContent`, and the matching
`Root` / `Item` / `Header` / `Trigger` / `Content` aliases.
