# @fictjs/scroll-area

Scroll area primitives for Fict UI primitives, modeled after
`@radix-ui/react-scroll-area`.

Exports `createScrollAreaScope`, `ScrollArea`, `ScrollAreaViewport`,
`ScrollAreaScrollbar`, `ScrollAreaThumb`, `ScrollAreaCorner`, and the matching
`Root` / `Viewport` / `Scrollbar` / `Thumb` / `Corner` aliases.
