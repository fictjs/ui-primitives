# @fictjs/toolbar

Toolbar primitives for Fict UI primitives, modeled after
`@radix-ui/react-toolbar`.

Exports `createToolbarScope`, `Toolbar`, `ToolbarSeparator`,
`ToolbarButton`, `ToolbarLink`, `ToolbarToggleGroup`,
`ToolbarToggleItem`, and the matching `Root` / `Separator` / `Button` /
`Link` / `ToggleGroup` / `ToggleItem` aliases.
