# @fictjs/hover-card

Hover card primitives for Fict UI primitives, modeled after
`@radix-ui/react-hover-card`.

Exports `createHoverCardScope`, `HoverCard`, `HoverCardTrigger`,
`HoverCardPortal`, `HoverCardContent`, `HoverCardArrow`, and the matching
`Root` / `Trigger` / `Portal` / `Content` / `Arrow` aliases.
