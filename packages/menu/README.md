# @fictjs/menu

Menu primitives for Fict UI primitives, modeled after
`@radix-ui/react-menu`.

Exports `createMenuScope`, `Menu`, `MenuAnchor`, `MenuPortal`,
`MenuContent`, `MenuGroup`, `MenuLabel`, `MenuItem`, `MenuCheckboxItem`,
`MenuRadioGroup`, `MenuRadioItem`, `MenuItemIndicator`, `MenuSeparator`,
`MenuArrow`, `MenuSub`, `MenuSubTrigger`, `MenuSubContent`, and the matching
`Root` / `Anchor` / `Portal` / `Content` / `Group` / `Label` / `Item` /
`CheckboxItem` / `RadioGroup` / `RadioItem` / `ItemIndicator` / `Separator` /
`Arrow` / `Sub` / `SubTrigger` / `SubContent` aliases.
