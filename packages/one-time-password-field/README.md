# @fictjs/one-time-password-field

One-time password field primitives for Fict UI primitives, modeled after
`@radix-ui/react-one-time-password-field`.

Exports `createOneTimePasswordFieldScope`, `OneTimePasswordField`,
`OneTimePasswordFieldInput`, `OneTimePasswordFieldHiddenInput`, and the
matching `Root` / `Input` / `HiddenInput` aliases.
