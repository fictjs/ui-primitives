# @fictjs/form

Form primitives for Fict UI primitives, modeled after
`@radix-ui/react-form`.

Exports `createFormScope`, `Form`, `FormField`, `FormLabel`, `FormControl`,
`FormMessage`, `FormValidityState`, `FormSubmit`, and the matching `Root`,
`Field`, `Label`, `Control`, `Message`, `ValidityState`, `Submit` aliases.
