# @fictjs/context-menu

Context menu primitives for Fict UI primitives, modeled after
`@radix-ui/react-context-menu`.

Exports `createContextMenuScope`, `ContextMenu`, `ContextMenuTrigger`,
`ContextMenuPortal`, `ContextMenuContent`, `ContextMenuGroup`,
`ContextMenuLabel`, `ContextMenuItem`, `ContextMenuCheckboxItem`,
`ContextMenuRadioGroup`, `ContextMenuRadioItem`,
`ContextMenuItemIndicator`, `ContextMenuSeparator`, `ContextMenuArrow`,
`ContextMenuSub`, `ContextMenuSubTrigger`, `ContextMenuSubContent`, and the
matching aliases.
