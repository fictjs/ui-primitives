# @fictjs/toast

Toast primitives for Fict UI primitives, modeled after
`@radix-ui/react-toast`.

Exports `createToastScope`, `ToastProvider`, `ToastViewport`, `Toast`,
`ToastTitle`, `ToastDescription`, `ToastAction`, `ToastClose`, and the matching
`Provider` / `Viewport` / `Root` / `Title` / `Description` / `Action` /
`Close` aliases.
