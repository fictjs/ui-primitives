# @fictjs/dropdown-menu

Dropdown menu primitives for Fict UI primitives, modeled after
`@radix-ui/react-dropdown-menu`.

Exports `createDropdownMenuScope`, `DropdownMenu`, `DropdownMenuTrigger`,
`DropdownMenuPortal`, `DropdownMenuContent`, `DropdownMenuGroup`,
`DropdownMenuLabel`, `DropdownMenuItem`, `DropdownMenuCheckboxItem`,
`DropdownMenuRadioGroup`, `DropdownMenuRadioItem`,
`DropdownMenuItemIndicator`, `DropdownMenuSeparator`, `DropdownMenuArrow`,
`DropdownMenuSub`, `DropdownMenuSubTrigger`, `DropdownMenuSubContent`, and the
matching aliases.
