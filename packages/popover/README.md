# @fictjs/popover

Popover primitives for Fict UI primitives, modeled after
`@radix-ui/react-popover`.

Exports `createPopoverScope`, `Popover`, `PopoverAnchor`, `PopoverTrigger`,
`PopoverPortal`, `PopoverContent`, `PopoverClose`, `PopoverArrow`, and the
matching `Root` / `Anchor` / `Trigger` / `Portal` / `Content` / `Close` /
`Arrow` aliases.
