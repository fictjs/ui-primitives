# @fictjs/dialog

Dialog primitives for Fict UI primitives, modeled after
`@radix-ui/react-dialog`.

Exports `createDialogScope`, `Dialog`, `DialogTrigger`, `DialogPortal`,
`DialogOverlay`, `DialogContent`, `DialogTitle`, `DialogDescription`,
`DialogClose`, `WarningProvider`, and the matching `Root` / `Trigger` /
`Portal` / `Overlay` / `Content` / `Title` / `Description` / `Close` aliases.
