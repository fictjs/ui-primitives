# @fictjs/navigation-menu

Navigation menu primitives for Fict UI primitives, modeled after
`@radix-ui/react-navigation-menu`.

Exports `createNavigationMenuScope`, `NavigationMenu`, `NavigationMenuSub`,
`NavigationMenuList`, `NavigationMenuItem`, `NavigationMenuTrigger`,
`NavigationMenuLink`, `NavigationMenuIndicator`, `NavigationMenuContent`,
`NavigationMenuViewport`, and the matching aliases.
