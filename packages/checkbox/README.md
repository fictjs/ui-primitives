# @fictjs/checkbox

Accessible checkbox primitives for Fict UI primitives, modeled after `@radix-ui/react-checkbox`.

Exports `createCheckboxScope`, `Checkbox`, `CheckboxIndicator`, `CheckboxProvider`, `CheckboxTrigger`, `CheckboxBubbleInput`, and the matching `Root`/`Indicator`/`Provider`/`Trigger`/`BubbleInput` aliases.
