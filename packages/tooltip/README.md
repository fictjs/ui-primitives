# @fictjs/tooltip

Tooltip primitives for Fict UI primitives, modeled after
`@radix-ui/react-tooltip`.

Exports `createTooltipScope`, `TooltipProvider`, `Tooltip`, `TooltipTrigger`,
`TooltipPortal`, `TooltipContent`, `TooltipArrow`, and the matching `Provider` /
`Root` / `Trigger` / `Portal` / `Content` / `Arrow` aliases.
